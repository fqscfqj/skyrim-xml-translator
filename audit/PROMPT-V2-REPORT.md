# 提示词 v2 与小模型翻译质量报告

- 日期：2026-11-12
- 目标：让 ~300B / 免费 flash 模型稳定读懂英文（及俄/日等）游戏原文，输出忠实、自然的简体中文；强化 NSFW 模式的成人强度；同时修掉会误导小模型的配套代码问题。
- 提示词草稿由 newapi/gpt-6-astra 子代理产出，主代理在真实网关（`z-ai/glm-5.3-flash`）上做 A/B、人工复核并整合。
- 验证：下文真实端点记录是早期草稿的历史快照，不代表当前提示词资源；当前离线测试结果以本次修复后的测试输出为准。本次修复未执行联网评测。

> 当前状态勘误：中英对照和露骨度校准例句已从发布提示词移除；下文带例句的 A/B 结果仅适用于当时草稿，不是当前实现的验收证据。当前核心系统提示离线字符数为 default 663、NSFW 907。

## 1. 发现的真实弱点（有实测证据）

### 1.1 提示词：规则抽象、没有例子、格式说明混在中间

旧 default 系统提示 ~1177 字符，NSFW ~2100 字符，加上文体规则后，短标签 “Health” 的请求约 1248 字符、成人对白约 2207 字符。内容以“锁定约束→必要消歧→目标语重组→一次核验”“谓词—论元关系”等抽象表述为主，没有可模仿的例子。

实测失败例：

```
The blade that slew the last dragon priest now rests in the hands of a farmer who has never drawn it.
旧提示词：那柄杀死最后一位龙祭司的利刃，如今落在一个从未出鞘挥斩过的农夫手中。
```

“从未出鞘挥斩过的农夫”把 draw（拔出）理解成出鞘，关系从句挂错。换成带 2 条同类例句的短提示词后：

```
那把斩杀最后一位龙祭司的利刃，如今落在一个从未拔出过它的农夫手中。
```

### 1.2 NSFW：模型倾向软化

旧 NSFW 提示词反复强调“不升级也不弱化”并堆叠同意条款，但缺少露骨度校准。实测：

```
I want you inside me. Now. Don't make me beg.
旧：我要你进来。现在。别逼我求你。
新：我要你插进来。就现在。别逼我求你。
```

用户明确要求强化成人强度，因此 v2 把“不弱化”写成可执行规则：禁止用“那里、下面、私密、结合、云雨、亲密”等含糊词替换原文明确的性器官或行为；原文粗俗用同等粗俗中文；禁止淡出、概括、加警告。

### 1.3 术语表污染：比提示词更隐蔽的质量杀手

用户术语表 75,872 条（含大量整句翻译记忆）。实测发现：

- “Health” 命中一条 `word_of_power`（龙语词墙）记录，译为“生命”。旧提示词要求“默认译名应全篇采用”，模型于是把 `Restore 20 points of Health.` 译成 **恢复20点生命。**（正确应为“生命值”）。
- 术语富元数据里的 `formid=0x...`、`sst_status=0` 被当作“备注：”注入提示词，纯属噪声。
- 短标签会携带 400-1000+ 字符的术语/参考条目，弱模型容易丢失原文。
- “相关条目”里 `Damage Health -> 生命减损` 又把刚过滤掉的“生命”带回来。

### 1.4 标识符误判：“One-Handed” 根本没被翻译

旧正则把“含连字符 + 两个大写字母开头”当内部 ID，直接把 `One-Handed` 原样返回，状态 warning、0 次模型调用。同理全大写普通词（如 `DRAGON`）也会被当成 ID。

### 1.5 质量检查误报（子代理审计）

`quality_checker.py` 会误判以下忠实输出：纯数字/符号标签（`50%`、`1000`）、中文夹英文名（`和 Gerdur 谈过之后再来找我。` 同文返回）、版本号（`v1.2.3`）、普通对白里的“抱歉/我无法……”（被当成模型拒绝）、短源文的双语重复（只记 warning，不重试）。另有 20k 嵌套引号导致 44 秒的二次方退化。

## 2. 已落地的改动

### 2.1 提示词（prompts/）

- **default**：四步“读懂→保真→落笔→自检”；当前不内置中英对照例句；中文表达/格式规则压缩为一段；内置提示词的 JSON 格式锚点在追加文体规则后仍保持最后一段；当前核心系统提示 663 字符。
- **nsfw**：保留普通文本的阅读理解步骤；条件触发成人尺度；明确反委婉、反淡出、反警告；保留动作角色/身体所属/同意拒绝胁迫，不补年龄与关系；当前不内置尺度例句，核心系统提示 907 字符。
- **style_profiles**：8 个文体 profile 压缩为 1-3 条可执行规则；对白补充“承接、犹豫、自我修正”、代词保留、身体所属；书籍补充“不丢关系时可调整句界”。
- **batch/retry/reformat/keywords**：缩短并通过实测；batch 输出锚点保留 id 精确匹配；retry 保留“只重做质量问题涉及的判断”“可见自然语言均应译出”等约束。关键词提示词移除了旧的“数组最多 12 项”人为上限，改由 `rag.keyword_max_queries` 控制最终数量（默认 128），避免长文本实体被截断；代码安全上限与日志保留。
- 提示词文件仍为可编辑 JSON，运行期热加载。

### 2.2 术语表卫生（src/translation/prompt_builder.py）

1. 内部元数据备注（`formid=`、`sst_status=`、`editorid` 等）不渲染；无文字的 ID 备注也不渲染。
2. 记录类型映射为中文领域标签（`word_of_power` → 龙语力量之语，`dialogue` → 对白……）；未知机器码不显示。
3. 短界面/物品名（≤60 字符、单一常见 UI 词、来源领域不兼容）不再作为默认译名；专名、多词术语、完整句 TM 永不受影响。
4. 被过滤词不再通过“相关条目”重新注入（如 `Damage Health -> 生命减损` 不会再把“生命”带回来）。
5. 整句完全命中的 TM 条目标注“整句命中，直接采用”并排在最前。
6. 短文本术语上下文独立预算（默认 1200 字符）；整体预算仍由 `rag.glossary_context_max_chars` 控制。
7. 新增配置：`rag.glossary_domain_filter_enabled`（默认 true）、`rag.short_text_glossary_max_chars`（默认 1200），GUI 高级 RAG 设置可调。

真实术语表端到端验证：

| 原文 | 改动前 | 改动后 |
|---|---|---|
| Restore 20 points of Health. | 恢复20点生命。 | **恢复20点生命值。** |
| Wait 24 hours for the renovations to finish | 等待24小时，让翻修完工 | **等待24小时装修完毕**（整句 TM 命中） |
| Report back to Jarl Balgruuf. | 向巴尔古夫领主复命。 | **回去向巴尔古夫领主报告。**（TM 命中） |

### 2.3 标识符启发式（src/translation/text_analyzer.py）

- 连字符 Title-Case 词（`One-Handed`、`Obi-Wan`）不再当内部 ID；带数字/下划线/全大写段（`SKSE-64`、`WB-Foo`）仍当 ID。
- 全大写但含元音的词（`DRAGON`、`THALMOR`）不再当 ID；无元音缩写（`SKSE`、`MCM`）仍按 UI token 处理。
- 结果：`One-Handed` 现在会真正送模型，实测输出“单手”（配合术语表可稳定为“单手武器”）。

### 2.4 质量检查（src/translation/quality_checker.py）

- 纯数字/符号标签保留为 warning；数字值改变仍为 error。
- 中文夹拉丁专名同文返回不再误判 identity。
- 版本号、单 token 全大写标签可原样保留；多词全大写句子（`DO NOT ENTER`）必须翻译。
- 中文目标下假名/西里尔/韩文等非汉字字母计入“外文”，不再放行。
- 模型拒绝识别加严格上下文门槛：普通台词“抱歉，我无法……”不再被误判；真正的“作为语言模型，我无法完成翻译任务”仍能识别。
- 短源文整句重复（双语输出）升级为 error；嵌套引号处理加上限，20k 嵌套从 44 秒降到 0.09 秒。
- 新增 25 个回归测试（`tests/test_quality_checker_small_model.py`）。

|---|---|---|
| 关系从句 blade/farmer | 从未出鞘挥斩过的农夫 | 从未拔出过它的农夫 |
| 代词 Gerdur/son | 格尔德/正确 | 正确 |
| 否定/范围 Thalmor | 有去无回（正确） | 正确 |

| NSFW inside me | 我要你进来 | 我要你插进来 |

## 4. 剩余风险与建议

1. **温度**：当前配置 `temperature: null`，采样随机性较高，同一术语可能一次“生命值”、一次“生命”。建议设 0.2-0.4（README 已写）。
2. **术语表质量**：过滤只能处理“短 UI 词 + 明确不兼容领域”；长句 TM 仍按全篇采用。若某条 TM 本身译错，需要用户修正术语表。
3. **嵌入检索延迟**：真实术语表 7.5 万条时，一句对话的 RAG 可能 20-30 秒（嵌入 API 占主要时间）；短文本本地关键词路径较快。可考虑换更快的 embedding 或用确定性扫描覆盖更多场景。
4. **弱模型固有波动**：例如 “我还开始以为”“伤疤在说着相反的话” 这类翻译腔仍会出现；提示词已给出自然中文示例，但 300B 模型无法保证每次最优。
5. **提示词仍可继续 A/B**：`audit/prompt_v2/variant_a|b` 保留了两套草稿与 RATIONALE，可在不同网关上继续比较。
